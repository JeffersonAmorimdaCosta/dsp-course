# Template de exportação dos Estudos 2 e 3

Adaptação do template [plain_latex](https://github.com/myst-templates/plain_latex), de Steve Purves, sob licença CC-BY-4.0. Usa papel A4, idioma português, fontes DejaVu e quebra de linhas nas listagens para acomodar código e saídas textuais dos notebooks. A estrutura dos capítulos permanece a do Estudo 1.
